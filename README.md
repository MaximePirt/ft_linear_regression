# ft_linear_regression

Introduction to the basic concepts behind machine learning. The program predicts the price of a car from its mileage, using a linear function trained with a gradient descent algorithm.

## Objective

The project implements this function:

`estimatePrice(mileage) = theta0 + theta1 * mileage`

The model is trained on a mileage/price dataset. The learned parameters (`theta0`, `theta1`) are then saved to a CSV file and reused by the prediction and evaluation programs.

## Features

- Simple linear regression with a single feature: `km`
- Standardization of the data before training
- Batch gradient descent, with `theta0` and `theta1` updated simultaneously
- Automatic stop on convergence (gradient norm) or on divergence (non-finite gradient)
- **Un-standardization** of the thetas after training: the saved parameters apply directly to raw mileage values
- Validation of the CSV files (columns, numeric types, NaN/inf, negative values) and of the user input
- A prediction program that estimates the price of a car
- An evaluation program using regression metrics (MSE, RMSE, MAE)
- A plot of the dataset and the regression line, saved as a PDF

## Dataset

The dataset (`src/data/data.csv`) contains two columns:

- `km`: the car's mileage
- `price`: the car's price

The goal is to learn the linear relationship between these two variables. The file is rejected if a column is missing, if a value is non-numeric, infinite, NaN or negative.

## Preprocessing

Before training, the kilometer values are standardized to improve the stability and convergence speed of the gradient descent:

```text
x_scaled = (x - mean) / std_deviation
```

`mean` and `std_deviation` are computed by hand (no library shortcut) and are only used during training.

## Training

`theta0` and `theta1` start at `0` and are updated at each iteration, following the subject's formulas:

```text
error  = estimatePrice(km) - price
theta0 = theta0 - learningRate * mean(error)
theta1 = theta1 - learningRate * mean(error * km)
```

Hyperparameters (in `calcul.py`):

| Name             | Value     |
|------------------|-----------|
| `learningRate`   | `0.1`     |
| `max_iterations` | `5000000` |
| `tolerance`      | `1e-9`    |

### Stopping conditions

Training stops when one of these happens:

1. **Convergence**: the norm of the gradient is below `tolerance`.
2. **Divergence**: the gradient becomes non finite. Nothing is saved, and the program exits with an error.
3. **Max iterations** reached.

The reason and the number of iterations are printed at the end of the training.

### Un-standardization

The thetas learned on standardized data are converted back so that they work on raw mileage:

```text
theta1_raw = theta1 / std_deviation
theta0_raw = theta0 - theta1 * mean / std_deviation
```

Only these two values are saved in `models/trained_params.csv`:

```csv
theta0,theta1
...,...
```

Since the saved thetas already apply to raw values, **`mean` and `std_deviation` are not stored**, and the prediction and evaluation programs do not need any standardization.

## Prediction

```text
Enter car's mileages please
```

The prediction program:

1. asks for a mileage and validates it (non-negative integer; `Ctrl+C`/`Ctrl+D` cancels cleanly),
2. loads `theta0` and `theta1` from `models/trained_params.csv`. If the file is missing or invalid, it falls back to `(0, 0)` as required by the subject,
3. computes `theta0 + theta1 * mileage`,
4. prints the estimated price (clamped to `0` if negative).

## Evaluation

`precision.py` loads the saved thetas and the dataset, then computes the errors of the model on raw `km` values.

#### MAE

The **Mean Absolute Error** is the average absolute error, in the same unit as the price.

```text
MAE = (1 / m) * Σ|prediction - real_value|
```

#### MSE

The **Mean Squared Error** is the average of the squared errors. It penalizes major errors more heavily.

```text
MSE = (1 / m) * Σ(prediction - real_value)^2
```

#### RMSE

The **Root Mean Squared Error** is the square root of the MSE, back in the same unit as the price.

```text
RMSE = sqrt(MSE)
```

## Launch the project

### 0. Install the dependencies

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 1. Train the model

The programs use relative paths (`data/`, `models/`, `outputs/`), so they must be run **from the `src/` folder**.

```bash
cd src
python train.py
```

This creates `models/trained_params.csv` and `outputs/figures/regression.pdf`, and displays the regression plot.

### 2. Predict a price

```bash
python prediction_main.py
```

### 3. Evaluate the accuracy

```bash
python precision.py
```

## Pipeline

```text
data.csv
   -> parsing and validation
   -> standardization of km
   -> gradient descent
   -> un-standardization of theta0, theta1
   -> saving theta0, theta1 (models/trained_params.csv)
   -> prediction / evaluation on raw km
```

## Key Points of the Project

- The saved thetas are expressed for raw mileage: no standardization is needed outside of `train.py`.
- Training convergence is decided by the gradient norm, not by a final quality metric.
- `MAE`, `MSE` and `RMSE` evaluate the final quality of the model.
- Without a trained model, the prediction program answers `0`.
